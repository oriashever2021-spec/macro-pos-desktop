# Agent Rules - Macro POS Desktop Wrapper

This folder is a thin desktop wrapper around the production POS web app.

Before changing this wrapper, read:

1. `README.md`
2. `../pos-poc/AGENTS.md`
3. `../pos-poc/docs/PRODUCT.md`
4. `../pos-poc/docs/DECISIONS.md`

The POS is already in production. Changes must be tested locally first. Do not
publish installers, deploy live changes, or alter production behavior unless the
owner explicitly approves after local testing.

For local-only code changes, do not ask permission before implementing. Make the
local change, verify it, summarize sharply, and ask the owner to test it.

Communication rule: save fluff. Use native, idiomatic, simple language. Be
surgical. Give an executive-sharp summary before and after changes, fixes, or
investigation results.
